# 📍 Buscador de CEP

Projeto desenvolvido em **Java** para consultar informações de endereço através de um CEP.

# Sobre o projeto

O Buscador de CEP permite que o usuário informe um CEP e receba os dados do endereço correspondente, como:

CEP
Logradouro
Bairro
Cidade
Estado

## Tecnologias

* Java
* API ViaCEP
* Gson

## Como funciona

O usuário informa um CEP e o sistema consulta a API, retornando informações como:

* CEP
* Logradouro
* Bairro
* Cidade
* Estado

## Objetivo

Projeto desenvolvido para praticar **Java, consumo de APIs e manipulação de JSON**.
